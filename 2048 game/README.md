🎮 2048 Game
2048 is a puzzle game where the player combines tiles with the same number to create larger values. The objective is to create a tile with the value 2048.

🎮 How to Play
Use the Arrow Keys to move the tiles:
⬆️ Up Arrow — Move tiles up
⬇️ Down Arrow — Move tiles down
⬅️ Left Arrow — Move tiles left
➡️ Right Arrow — Move tiles right
When two tiles with the same number collide, they merge into one tile.

After each move, a new tile appears on the board.
Continue combining tiles and try to reach 2048!
