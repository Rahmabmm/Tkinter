# ✿ Cute Sudoku ✿

A colorful and interactive Sudoku game built with **Python and Tkinter**.

The game combines the classic Sudoku puzzle with a cute interface, difficulty levels, limited lives, and hints.

## 🎮 How to Play

The goal is simple: **complete the 9×9 Sudoku grid correctly.**

1. Choose a difficulty: **Easy, Medium, or Hard**.
2. Click on an empty cell.
3. Enter a number using the number pad or your keyboard.
4. If your number is incorrect, you lose a ❤️ life.
5. Use ✨ hints when you need help.
6. Complete the entire grid to win!

### 🖱️ Controls

| Action             | How to use                                       |
| ------------------ | ------------------------------------------------ |
| Select a cell      | Click on a cell                                  |
| Enter a number     | Click a number on the pad or press `1–9`         |
| Erase              | Click **Erase**, or press `Backspace` / `Delete` |
| Move between cells | Use the `↑ ↓ ← →` arrow keys                     |
| Notes              | Click **Notes** or press `N`                     |
| Use a hint         | Click **Hint**                                   |
| Start a new game   | Click **New**                                    |

## 🎯 Difficulty Levels

| Difficulty | Clues | ❤️ Lives | ✨ Hints |
| ---------- | ----: | -------: | ------: |
| Easy       |    42 |        6 |       2 |
| Medium     |    34 |        4 |       4 |
| Hard       |    28 |        3 |       5 |

Higher difficulty means fewer starting clues and fewer lives, making the puzzle more challenging.
